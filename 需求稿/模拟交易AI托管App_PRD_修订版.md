## 一、产品概述

### 1.1 背景与目标
为缺乏时间盯盘或交易经验的投资者提供「模拟交易 + AI托管」应用。新用户获得 50 万模拟资金在零风险环境体验真实交易；核心价值是「财团托管」——用 Trade Master 深度分析引擎（多智能体财团）自动管理模拟仓位、验证 AI 策略有效性。

### 1.2 目标用户
- 缺乏专业金融知识与盯盘时间的上班族。
- 对 AI 量化 / 智能投顾感兴趣、想低成本验证策略的投资者。
- 需要复盘或策略测试的金融爱好者。

### 1.3 核心价值主张
- 零风险体验：真实市场数据，无资金风险。
- 极简建仓：截图 / 文本一键同步真实券商持仓，自动生成模拟账户。
- AI 智能托管：「财团」全自动调仓，每笔调仓附带可追溯的分析报告。

### 1.4 合规与免责
- 全产品常驻免责声明：「模拟交易数据，仅供学习与研究，不构成任何投资建议」。
- 模拟盘与真实账户严格隔离；不提供真实交易、不出金。

## 三、登录与账户初始化

### 3.1 登录（Web）
- 手机号 + 短信验证码（获取验证码 → 输入 → 登录）。验证码 60s 重发、5 分钟有效。
- 无第三方登录、无密码登录。
- 未勾选《用户协议》时登录按钮禁用。
- 新用户登录后自动初始化账户（见 3.2）。

### 3.2 账户与双簿模型（账务规则·上）
账户下有两本**相互独立**的持仓簿：

- **镜像簿（持仓页 / 同步流程）**——镜像你的真实券商持仓：
  - 未同步：50 万种子现金 + 空持仓（体验用）。
  - 同步：任何时点「一般同步」覆盖为最新真实持仓快照，**无限制**。
  - 首页同步**不影响托管簿**。

- **托管簿（财团托管）**——托管 AI 实际操作的一本账：
  - 开启托管前，须在托管页**粘贴持仓截图** → 建立托管簿起始持仓（快照，现金 0）。
  - 之后只被托管调仓（AI 买卖）改变；首页同步不触碰。
  - 托管簿的同步 / 重建见 §3.3。

- **展示口径**：
  - **交易首页资产看板 = 合并口径**：总资产 = 镜像簿总资产 + 托管簿总资产（用户裁定）。托管开启时首页显示「AI托管运行中」状态条。
  - **财团托管页 / 归因看板 = 只看托管簿**。
  - 数据模型仍双簿独立存，首页合并为展示层求和。

### 3.3 托管簿规则
1. 起点 = 托管页粘贴的持仓快照（OCR 成本价入库、现价计市值），**可用资金 = 0**（用户裁定：先卖后买、换仓式，无凭空资金）。
2. 现金 0 约束的含义：托管买需资金以「卖出解锁」为限 → 托管实际为**组合再平衡/换仓**（评级 Buy = 提高目标仓位，需先卖出减配标的解锁资金；全市场候选买入同样受此约束）。
3. **重贴快照 = 重建托管簿**（2026-09 改，原先「已有成交记录就不许重贴」的拦截已取消）：
   - 允许直接重新粘贴；提交时自动清空该簿的**委托 / 成交 / 次日行动计划**（「监控条件」是次日计划的派生视图，随之清空）；
   - 再用本次快照**覆盖持仓、成本价、可用资金**，原托管簿的持仓与流水不可恢复；
   - **同时关闭托管开关**（`is_active=false`），需回「策略设置」手动重开 AI 才会继续调仓。
     关开关不是顺手清理：计划清空后执行层 `has_plan=False` 会回落到「按 `engine_runs` 旧评级兜底」的路径，那里读的是**旧仓位**留下的评级，下一个 cron tick 就会按旧评级对**新仓位**下单，且不校验开市时间。
   - 提示：粘贴面板第 1 步（解析之前）即常驻横幅写明后果，点提交时再 `confirm` 二次确认。
   - 「清空成交记录（重置托管）」独立保留，语义是**回到未建簿状态**（只清空、不覆盖）。
4. 托管收益率 / 归因只基于托管簿，从托管簿建立之日起算；与镜像簿、手动操作互不混算。
5. 关闭托管：停止调度，保留托管簿与流水；可从托管设置重置。

## 四、交易模块页面需求

### 4.1 交易首页 `/trade`
- 顶部资产看板：总资产（最大字号）、浮动盈亏（带色）、总市值、当日参考盈亏；小眼睛切换显隐（****）。
- **总资产口径 = 合并（镜像簿 + 托管簿）**；下方可展开分看「首页 / 托管」各自资产。
- 点资产数字区切换「总盈亏 / 日盈亏」。
- 中部 2×2 功能宫格：持仓 / 财团托管 / 模拟量化(占位) / 自选股票。
- 财团托管开启时：宫格图标带绿色状态点/呼吸灯；资产看板上方出现「AI托管运行中」状态条（品牌蓝 20% 透明度 + 微光动效），点击可看托管日志摘要。
- 下拉刷新（15s 级轮询）；资产接口超时展示上次缓存 + 顶部提示「数据同步延迟」。
- 空状态（未同步/未持仓）：浮动盈亏、总市值显示 0.00，引导「去同步持仓」。

### 4.2 持仓页 `/positions`
- 顶部资产摘要条（吸顶）：总资产 | 总市值 | 浮动盈亏 | 当日盈亏。
- 持仓列表（StockListItem）：
  - 左：股票名（主）、代码（次，含市场后缀）；
  - 右：现价（大字号带色）、当日盈亏（小字号带色）；
  - 下：持仓/可用、成本价、仓位占比进度条。
- 右上角/悬浮「同步持仓」按钮 → 同步 Sheet（输入→解析→确认→成功/失败，见 §6.2）。
- 点列表项 → 个股详情（4.4）。
- 行情异常：现价显示「–」，盈亏暂停更新并提示。
- 空状态插画 + 「去同步持仓」按钮。

### 4.3 自选股票页 `/watchlist`
- 自选列表：名称/代码/现价/涨跌幅。
- 添加：搜索框（代码/名称）→ 加入自选；支持 A股/港股/美股。
- 删除：左滑/长按删除。
- 自选为空时：插画 + 「搜索添加」引导。
- 作用：作为托管「仅限自选」范围的标的池；托管建议新增的候选（§6.3.4）可直接加自选。

### 4.4 个股详情页 `/stock/{code}`（本期新增）
- 分时 + 日 K（成交量副图）；K 线数据取 Wind OHLCV。
- 摘要：现价、涨跌幅、今开/最高/最低、成交量、换手、PE/PB（Wind）。
- 入口：「深度分析」→ 跳转 **AI 对话助手**并预填该标的（如「深度分析 600519」），由对话助手异步跑引擎、出报告卡片；「加入自选」。
- 持仓/自选列表点击进入。

### 4.5 财团托管页 `/trust`
- 顶部：托管状态条（运行中/已停止）+ 托管收益率/Agent 操作次数。
- 策略范围入口、托管设置入口。
- 展示的是**托管簿**（与首页镜像簿独立，§3.2）。
- **首次进入（托管簿未建立）**：空状态插画 + 「先粘贴你的持仓截图，创建托管起始仓位」+「粘贴持仓截图」按钮 → Sheet 解析 → 确认 → 建立托管簿 → 托管开关才可开启。
- 汇总与持仓列表 UI 同持仓页；托管开启时列表出现「AI调仓」标签，点击查看该笔调仓分析报告（读决策库，见 §6.3）。
- 关闭托管需二次确认；关闭后停止 Agent 决策、保留托管簿。

### 4.6 托管设置页 `/trust/settings`
表单列表：
- 托管开关（大 Switch，开启二次确认弹窗）。
- 操作范围 Radio：**仅限持仓股 / 仅限自选股 / 全市场**（三项，以 UI 稿为准）。
- 托管风格 Radio：保守 / 均衡 / 进取（预设档位，影响目标仓位与换手强度，见 §6.3.6）。
- 风控参数（可选）：单日最大交易次数、单票最大仓位、单票止损比例。
- **费用设置（新增，用户填写）**：佣金费率、是否免 5 元（免五）、印花税费率；默认预设 A股 佣金万 2.5 最低 5 元 + 卖出印花税 0.05%。
- 通知设置：飞书 / 企微 / 邮件 Webhook 或邮箱，各带启用开关。
- **清空成交记录（重置托管）**：仅当存在成交记录时可见；二次确认后删除委托/成交流水、次日行动计划（监控条件随之清空）与托管簿持仓，回到**未建簿**状态。重新粘贴快照已不再需要先走这一步（重贴会自动重建）。
- 修改即时生效并记录日志。

### 4.7 托管归因看板 `/trust/analytics`（本期新增）
- 托管收益曲线（自开启托管日起）、累计收益率、Agent 操作次数。
- 归因列表：每笔 AI 调仓（时间/标的/方向/金额/AI 原因/贡献盈亏）。
- 手动操作不计入托管业绩（本期无手动下单）。

### 4.8 当日委托 / 当日成交 `/records`
- 顶部 Tab：[委托] [成交]；时间倒序列表。
- 委托项：时间、名称、方向、委托价、数量、状态（已报/已成/已撤/废单）。
- 成交项：时间、名称、方向、成交价、数量、金额、AI 原因（仅托管）。
- 点单笔（托管产生）→ 弹出「AI 调仓分析报告」卡片。
- 空状态「暂无交易记录」。

### 4.9 模拟量化（占位页）
- 居中插画 + 「模拟量化即将上线」+ 提示后续支持（回测/量化策略，对齐 StrategyConfig）。
- 不提供预约收集。

## 六、核心业务流程

### 6.1 冷启动
下载打开 → 手机号登录 → 初始化 50 万账户 → 交易首页引导 → 进入持仓页「同步持仓」。

### 6.2 持仓同步流程（OCR + 账务，镜像簿）
> 指首页/持仓页「一般同步」（更新**镜像簿**，无限制）。托管簿的建立/重置单独走 §3.3（托管页粘贴快照）。

1. 点击「同步持仓」→ Sheet（支持粘贴文本或上传截图）。
2. 上传 → 后端 OCR/NLP 解析（名称/代码/数量/成本价），**服务端不持久化原始图片**。
3. 返回解析结果预览，用户可手动修正错认代码/数量。
4. 确认 → 覆盖镜像簿为最新快照（首次同步清 50 万种子；随时可再同步）。**不影响托管簿**。
5. 调行情计算实时盈亏 → 刷新持仓页。
- 置信度低：提示「部分信息识别不清，请手动补充或重新截图」。
- 解析响应 < 3s。

### 6.3 财团托管运行模型（两级：计划层 + 执行层）
托管 ≠ 每笔实时跑深度分析。运行如下：

**A. 计划层（慢：深度引擎）**
1. 触发：每交易日**收盘后**批量执行；托管开启时也可手动「立即生成计划」。
2. 对"在管标的"（按范围，见 6.3.4）**并行**跑 `run_analysis(ticker, date)`：
   - 同标的同日期命中缓存（`engine_run`）不重跑。
   - 产物 = 评级 `{Buy/Overweight/Hold/Underweight/Sell}` + 分节报告，写入决策库。
3. 把评级翻译为「次日动作与目标仓位」（映射表由执行层规则定义，见 6.3.3）。

**B. 执行层（快：分钟级调度器，单笔 <500ms）**
4. 交易时段内**每分钟**扫 Wind 行情，逐在管标的比对「最新计划动作」：
   - Buy/Overweight 且当前仓位 < 目标 → 生成买入委托；
   - Underweight/Sell → 减/清仓委托；
   - Hold → 不动。
5. **硬风控实时触发**（不依赖深度引擎）：单票止损线触发 → 立即卖出；单日次数/单票仓位上限 → 拦截新买入。
6. 命中 → 校验资金/持仓/市场规则 → 生成委托 → 撮合（§7）→ 成交 → 更新账务 → 生成一行 `ai_reason`（快模型）→ 触发通知（§6.5）。
7. 500ms 仅指「信号比对 + 校验 + 撮合」链路，不含 LLM 与深度分析。

**C. 报告查看**
8. 列表/流水点「AI调仓报告」→ 读决策库；对**新标的**（候选池建议加仓但无深度分析）现场异步触发一次深度分析，完成后推送。

#### 6.3.1 调仓依据
以深度引擎评级为主信号；Bull/Bear/Portfolio Manager 多智能体产出即为「财团」决策。托管 Agent 按评级动作，不自行临场判断（把判断收敛到引擎）。

#### 6.3.2 标的池（按用户选择）
- 仅限持仓：在管 = **托管簿**当前持仓（不是首页镜像簿）。
- 仅限自选：在管 = 自选列表。
- 全市场：不做全 A 实时扫描。在管 = **持仓 + 自选 + Agent 候选池**；Agent 每日从 Wind 涨跌幅/资金流/新闻粗筛 **≤3 只候选**做深度分析，给出「建议新增」（加入需用户确认或自动入候选）。

#### 6.3.3 评级 → 动作映射（默认规则，执行层可配）
| 评级 | 动作 |
|------|------|
| Buy | 加仓至目标仓位（风格档位决定目标仓位） |
| Overweight | 小幅加仓 |
| Hold | 持有不动 |
| Underweight | 减仓一半或至目标低配 |
| Sell | 清仓 |

#### 6.3.4 硬风控（不可关）vs 可选参数
- 硬校验：资金/持仓充足、A股 100 股取整、T+1 可用、涨跌停/停牌不可成交、单票仓位上限硬顶。
- 可选参数（托管设置）：单日最大交易次数、单票最大仓位、单票止损比例。

#### 6.3.5 风格档位（预设）
| 档位 | 单票目标仓位上限 | 换手倾向 |
|------|------------------|----------|
| 保守 | ≤ 20% | 低，Hold 多 |
| 均衡 | ≤ 30% | 中 |
| 进取 | ≤ 50% | 高，Sell 果断 |

#### 6.3.6 生命周期与异常
- 关闭托管：二次确认 → 立即停止执行层调度；保留托管簿与流水；决策库保留。
- Agent 服务异常：自动暂停托管，通知「AI 服务暂时不可用，已为您暂停托管」；镜像簿与手动数据不受影响。
- 托管收益率口径：从托管簿建立当日起算，归属托管；手动/镜像簿操作不混入。
- 双簿与同步的关系（§3.2 / §3.3）：
  - 首页/持仓页「一般同步」**无限制**，只改镜像簿，**不影响托管簿**；
  - 托管簿只在托管页建立/重建：重新粘贴快照即**自动重建**（清空委托/成交/次日行动计划与监控条件、覆盖持仓、关闭托管开关，粘贴前横幅提示 + 提交二次确认）；不覆盖只清空时用「清空成交记录（重置托管）」。

### 6.4 模拟委托 → 成交流程
1. 发起（托管执行层）。
2. 校验资金/持仓/市场规则 → 生成委托（已报）→ 记录流水。
3. 撮合（见 §7）→ 成交则更新持仓/资金，生成成交记录，触发通知；未成交按规则置「已撤/废单」。
4. 同一笔托管调仓的资金与持仓变动在**同一事务**完成。

### 6.5 仓位变动通知
1. 成交触发 → 读通知配置（飞书/企微/邮件 webhook、站内消息）。
2. 内容：股票、方向、数量、价格、AI 原因摘要。
3. 失败重试 3 次，仍失败记录日志 + 站内消息中心兜底。

## 七、撮合与费用规则

### 7.1 撮合
- 成交价：**现价即时成交**（Wind 最新价）。
- 委托仅支持市价式即时成交，不做限价排队与部分成交（本期简化）。
- A股：100 股/手取整、**T+1**（当日买入不可卖）、涨跌停/停牌不可成交。
- 港股：按股撮合（不做精确手数）；美股：T+0、无涨跌停。
- 卖出校验可用数量（T+1 冻结）；买入校验可用资金。

### 7.2 费用（用户可配置）
- 用户在托管设置填写：佣金费率、是否免 5 元、印花税费率。
- 默认预设：佣金 = 成交额 × 万 2.5（最低 5 元，可免五）；印花税 = 卖出成交额 × 0.05%（仅 A股）。
- 费用从可用资金扣减；港股/美股暂沿用同一套用户配置（分市场独立为后续项）。

## 九、非功能性需求

- 行情数据源：**Wind**（资产/持仓/委托行情 + 托管分钟级扫描 + 深度分析）。
- 轮询频率：交易首页/持仓页 15s 级；托管执行层 60s 级（控 Wind 调用量与成本）。
- 性能（内测规模，并发数十）：
  - 首页/持仓加载 < 1s；持仓解析 < 3s；
  - 托管**单笔执行链路 < 500ms**（不含 LLM/深度分析）；
  - 深度分析单标的全量跑约 10–15 分钟（异步）。
- 降级与文案：
  - Wind 余额不足/鉴权失败 → 明确提示「行情服务欠费/鉴权失败，请联系管理员」，不复用"无数据"文案（沿用 VendorRejectedError 机制）。
  - 托管 Agent 异常 → 自动暂停托管并通知用户。
  - 行情接口异常 → 前端现价显示「–」。
- 一致性：托管调仓的资金/持仓变动同事务；委托/成交最终一致。
- 安全：全站 HTTPS；原始截图不落库，仅存解析结果；模拟盘与真实账户隔离。
- 可用性：核心链路 ≥ 99%（内测档）。
