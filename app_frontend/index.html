底部 Tab 导航规范

本应用采用底部固定 Tab 导航，含三个核心入口：交易（默认）、模拟交易与 AI Agent。历史回测不单独占 Tab —— 它是「模拟交易 → 托管总览」内的一张入口卡片。遵循 8pt 网格系统，胶囊式容器圆角 22px，选中态使用品牌色填充。

设计规范
  • 容器高度 50 + 安全区域（Home Indicator）
  • 图标尺寸 24×24，选中时品牌色 #2962FF
  • 文字 10pt，未选中 #757575，选中 Medium
  • 胶囊圆角 22px，选中态品牌色填充
  • 3 个 Tab：交易 + 模拟交易 + AI Agent
  • 二级入口不占 Tab：历史回测挂在「模拟交易 → 托管总览」
  • Tab 切换无过渡或极短淡入淡出（150ms）
交互动效
  • 数字变化使用 CountUp 动画（300ms）
  • 下拉刷新自定义 Loading 动画
  • Tab 切换 150ms 极短过渡
  • 盈亏颜色变化：背景短暂闪烁绿/红（Opacity 10% → 0%）
  • 托管开启：Switch 弹跳 + 状态条渐变显现
